# 부동산 실습

서울시 아파트 실거래 데이터로 **웹 대시보드**를 만든 기록입니다.
데이터 확인 → 기획(PRD) → 구현 → 검증 순서로 진행했습니다.

**만든 것**

| 페이지 | 설명 |
|---|---|
| [`index.html`](index.html) | 대시보드 본체 — 요약 4장 + 차트 3종 + 탐색 도구 2종 |
| [`schema.html`](schema.html) | 구조 설명서 — 어떤 자료가 어떻게 화면이 되는지 그림으로 |
| [`PRD.md`](PRD.md) | 기획 문서 — 페르소나, 지표 정의, 완료 기준 |

## 1. 다룬 데이터

국토교통부 서울 아파트 실거래 신고 자료입니다.

| 항목 | 값 |
|---|---|
| 기간 | 2025년 7월 ~ 2026년 6월 (12개월) |
| 전체 | 320,141건 |
| 매매 | 72,459건 ← **주로 사용** |
| 전세 | 129,649건 ← 전세가율 계산에만 사용 |
| 월세 | 118,033건 ← 사용 안 함 |
| 범위 | 25개 구 · 316개 동 · 8,031개 단지 |

매매만 주로 쓴 이유는, 하나의 메시지를 분명하게 전하기 위해서입니다.
전세는 "전세가율" 하나를 계산할 때만 끌어왔습니다.

## 2. 데이터에서 알아낸 것

### 시장은 양극화됐습니다

2025년 하반기 대비 2026년 상반기, 구별 중위 평당가 변화율입니다.

| 많이 오른 구 | | 떨어진 구 | |
|---|---|---|---|
| 서초구 | **+21.3%** | 서대문구 | **−9.1%** |
| 송파구 | +19.7% | 은평구 | −4.8% |
| 용산구 | +17.1% | 양천구 | −4.5% |
| 성동구 | +16.6% | 종로구 | −3.8% |
| 강남구 | +13.9% | 강북구 | −1.3% |

### 진입장벽은 두 겹입니다

전세가율(매매가 대비 전세보증금 비율)이 낮을수록, 전세를 끼고 사도 직접 넣어야 할 돈이 큽니다.

| 전세가율 최저 | | 전세가율 최고 | |
|---|---|---|---|
| 강남구 압구정동 | **15.7%** | 금천구 가산동 | **90.8%** |
| 영등포구 여의도동 | 23.8% | 광진구 화양동 | 87.4% |

비싼 동네일수록 전세가율이 낮습니다 (상관계수 **−0.787**).
집값이 높은 데다 전세로 메울 몫도 작아서, 부담이 이중으로 걸립니다.

> **주의** — "많이 오른 곳일수록 갭이 크다"는 말은 성립하지 않습니다.
> 상승률과 전세가율의 상관은 −0.276으로 약합니다. 강한 것은 **가격 수준**과의 관계입니다.

### 예산별로 갈 수 있는 곳

거래의 30% 이상이 예산 안에 들어오는 동네 수입니다.

| 예산 | 진입 가능 동네 |
|---|---|
| 5억 | 33개 |
| 8억 | 98개 |
| 10억 | 151개 |

## 3. 화면 구성

위쪽은 읽어 내려가는 **요약**, 아래쪽은 눌러보며 찾는 **도구**입니다.

| 순서 | 화면 | 답하는 질문 |
|---|---|---|
| 01 | 큰 숫자 네 개 | 서울 전체가 지금 어떤 상태인가 |
| 02 | 구별 막대그래프 | 어느 구가 오르고 어느 구가 빠졌나 |
| 03 | 월별 그래프 | 1년 동안 어떻게 움직였나 |
| 04 | 동네 순위 | 가장 크게 움직인 동네는 어디인가 |
| 05 | **예산 탐색기** | 내 예산으로 어디를 갈 수 있나 |
| 06 | 구 선택 표 | 그 구 안에서 동네끼리 어떻게 다른가 |
| 07 | **전세가율 그래프** | 실제 진입장벽은 어떻게 작동하나 |
| 08 | 맨 아래 안내 | 어디까지 믿어도 되나 |

05 · 07번은 같은 데이터로 만든 다른 대시보드에는 없는 부분입니다.

## 4. 만든 방식

원본은 27.5MB입니다. 그대로 보내면 사이트가 느려지므로, **미리 계산해 요약해 둔 뒤** 그 요약본만 방문자에게 보냅니다.

```
원본 CSV          요약 계산            요약 파일         웹사이트
27.5MB    ──▶   build/aggregate.js  ──▶   227KB   ──▶   화면
320,141행        (방문 전에 미리)         120배 작음
```

- 차트는 **라이브러리 없이 직접 그렸습니다**. 외부 서비스가 멈춰도 화면이 깨지지 않습니다.
- 디자인은 원티드의 공개 디자인 시스템 [Montage](https://github.com/wanteddev/montage-web) 토큰을 가져와 맞췄습니다.
- 구조 설명서의 도식은 [diagram-design](https://github.com/cathrynlavery/diagram-design) 규격을 따랐습니다.

자세한 흐름은 [`schema.html`](schema.html)에 그림으로 정리해 두었습니다.

## 5. 검증에서 잡아낸 오류

계산 결과가 **그럴듯해 보이는데 틀린** 경우가 세 번 있었습니다. 이 실습에서 가장 배운 부분입니다.

### ① 전세가율이 119%로 나왔다

동네 전체를 한 덩어리로 묶어 비교했더니 **전세가 매매보다 비싼** 값이 나왔습니다.
30년 된 소형 아파트의 전세금과 신축 대형의 매매가가 한 계산에 섞인 탓입니다.
→ **같은 아파트·같은 평수끼리** 묶어 계산하도록 바꿨습니다. 이상치가 0건이 됐습니다.

### ② 예산 탐색기가 실제보다 적게 셌다

10억 기준으로 147개 동네를 찾았는데 실제 답은 151개였습니다.
아파트 가격이 6억·9억·12억처럼 **딱 떨어지는 금액에 몰려 있고**(전체의 25.6%),
가격 구간의 경계 처리가 그 거래들을 빠뜨리고 있었습니다.
→ 경계 방식을 바꾸고 예산 입력을 5,000만원 단위로 맞췄습니다. 오차가 **정확히 0**이 됐습니다.

### ③ 없는 상관관계를 주장할 뻔했다

"많이 오른 곳일수록 갭이 크다"를 쓰려다 실제로 계산해 보니 −0.276으로 약했습니다.
강한 것은 "**비싼** 곳일수록 갭이 크다"(−0.787) 쪽이었습니다.
→ 문장을 사실에 맞게 고치고, 약한 상관은 약하다고 화면에 밝혔습니다.

**표본이 부족하면 숫자를 만들지 않습니다.** 316개 동네 중 변화율은 211개, 전세가율은 214개만 값이 있고, 나머지는 `—`로 비워 두었습니다. 0으로 채우면 "값이 0"과 구분되지 않기 때문입니다.

## 6. 남은 일

### 화면 맨 위 "−6.5%"가 오해를 부릅니다

서울 전체를 한 줄로 세운 가운데 값은 6.5% 내려갔습니다.
그런데 바로 아래 그래프에서는 **25개 구 중 18개가 올랐습니다**.

둘 다 맞는 값입니다. 내려간 것은 가격이 아니라 **거래의 구성**입니다.
값싼 동네의 거래가 크게 늘었습니다 — 노원구 비중 7.8% → 11.8%,
반대로 값비싼 성동구는 4.5% → 2.3%로 줄었습니다.
싼 동네가 많이 거래되면 각 동네가 올라도 전체 가운데 값은 내려갑니다.

거래량을 감안하면 **구 평균은 +5.0%**입니다.
→ 큰 숫자를 +5.0%로 바꾸고, −6.5%는 설명과 함께 작게 붙일 예정입니다.

### GitHub Pages가 아직 켜져 있지 않습니다

배포 설정은 올려두었지만 저장소 설정에서 한 번 켜 주어야 합니다.
**Settings → Pages → Source**를 **"GitHub Actions"**로 바꾸면 자동 배포가 시작됩니다.

## 7. 파일 안내

모두 이 폴더(`부동산-실습/`) 안에 있습니다.

| 경로 | 내용 |
|---|---|
| `index.html` | 대시보드 |
| `schema.html` | 구조 설명서 |
| `PRD.md` | 기획 문서 |
| `assets/` | 화면 디자인과 동작 |
| `build/` | 요약 계산 · 검증 스크립트 |
| `data/` | 계산된 요약 파일 (227KB) |
| `seoul-apt-latest.csv` | 원본 데이터 (27.5MB) |
| `analyze.py` | 수업에서 쓴 최초 분석 스크립트 (기록용, 현재 데이터로는 동작하지 않음) |

요약을 다시 계산하려면 — 원본 데이터가 바뀔 때만 필요합니다.

```bash
cd 부동산-실습 && node build/aggregate.js
```

계산 결과가 맞는지 확인하려면 (30개 항목 검사).

```bash
cd 부동산-실습 && node build/verify.js
```
