# PRD — 무료 게임(F2P) 카탈로그 대시보드

**작성일** 2026-08-12 · **기획** Opus · **구현** Sonnet · **배포** GitHub Pages
**산출물** `games.html` (신규 페이지, 기존 `index.html`은 그대로 유지하고 상호 링크)

---

## 1. 한 줄 정의

FreeToGame이 수집한 **무료 PC 게임 328종**(1997~2024)을 장르·출시연도·게임 나이 축으로 분석해
**"무료 게임 시장은 어떤 장르에 쏠려 있고, 그 쏠림은 시대에 따라 어떻게 바뀌었는가"**
를 한 페이지에서 답하고, 그 아래에서 328종을 직접 검색·필터로 탐색하게 하는 **인사이트 + 탐색기** 결합 페이지.

## 2. 페르소나 & JTBD

**페르소나** — 게임 시장을 훑는 기획자/분석가.
표본 수와 계산 기준이 드러나야 인용하고, 숫자를 본 다음에는 실제 게임 목록을 직접 뒤져보고 싶어한다.

| # | Job | 대응 섹션 |
|---|-----|----------|
| J1 | 무료 게임 시장의 장르 구조를 30초 안에 파악한다 | S1, S2 |
| J2 | 출시가 언제 몰렸는지 시계열로 확인한다 | S3 |
| J3 | 장르 쏠림이 시대별로 어떻게 교체됐는지 본다 | S4 |
| J4 | 이 카탈로그가 얼마나 오래된 게임으로 유지되는지 확인한다 | S5 |
| J5 | 조건에 맞는 게임을 직접 찾아 원본 페이지로 넘어간다 | S6 |

## 3. 데이터

**원본** `free-to-play-games.csv` (96KB, 328행 + 헤더, UTF-8)
원본 파일명은 `archive.zip` 안의 `Free-to-play games`(확장자 없음)이며, 리포에는 `free-to-play-games.csv`로 커밋한다.

**컬럼** `title, thumbnail, short_description, game_url, genre, platform, publisher, developer, release_date, freetogame_profile_url`

| 항목 | 값 |
|------|-----|
| 행 수 | 328 (중복 title 0건, 빈 셀 0건, 날짜 형식 이탈 0건) |
| 출시일 범위 | 1997-01-07 ~ 2024-06-22 (중위 2016-05-06) |
| 장르 | 원본 18종 → 정제 후 **12종** (§3.2) |
| 플랫폼 | `PC (Windows)` 317 / `PC (Windows), Web Browser` 11 |
| 퍼블리셔 | 258곳 (최대 보유 6종) · 개발사 288곳 |
| 결측 | 없음 |

### 3.1 CSV 파싱 주의

`short_description`, `publisher`, `developer`, `title`에 **쉼표를 포함한 따옴표 필드**가 있다
(예: `"KRAFTON, Inc."`, `Warhammer 40,000: Warpforge`).
단순 `split(',')`은 데이터를 깨뜨린다. **따옴표(이스케이프 `""` 포함)를 처리하는 파서를 반드시 쓸 것.**
정상 파서로 328행 전부 컬럼 수 10이 맞는지 빌드 단계에서 assert한다.

### 3.2 장르 정제 정책 (사용자 결정: 통합 + 각주)

**1단계 — 동의어 병합**

| 원본 | → | 정제 |
|------|---|------|
| `Card` (3) | → | `Card Game` |
| `ARPG` (1) | → | `Action RPG` |
| `MMOARPG` (1) | → | `MMORPG` |
| `Action Game` (1) | → | `Action` |

**2단계 — 1단계 후 표본 3건 미만 장르는 `기타`로 묶는다**
→ `Action RPG`(2: Genshin Impact, Lost Ark), `Action`(2: One Punch Man: World, Deceit 2), `Fantasy`(1: Transformice) = **기타 5종**

**정제 결과 (합계 328, 검증 완료)**

| 장르 | 게임 수 | 비중 |
|------|--------:|-----:|
| MMORPG | 127 | 38.7% |
| Shooter | 93 | 28.4% |
| Card Game | 30 | 9.1% |
| Strategy | 19 | 5.8% |
| MOBA | 18 | 5.5% |
| Fighting | 9 | 2.7% |
| Sports | 9 | 2.7% |
| MMO | 6 | 1.8% |
| 기타 | 5 | 1.5% |
| Battle Royale | 5 | 1.5% |
| Social | 4 | 1.2% |
| Racing | 3 | 0.9% |

> `MMO`(6종, 샌드박스/월드 계열)는 `MMORPG`와 합치지 않는다 — 원본이 구분해 표기한 별개 값이고,
> 병합하면 헤드라인 수치가 근거 없이 부풀려진다.
> 위 병합·묶음 내역은 **S7 푸터 '데이터 한계'에 그대로 명시**한다(사용자 요구).

## 4. 검증된 핵심 인사이트

> 아래 수치는 기획 단계에서 원본 CSV로 직접 계산해 검증했다.
> 구현 결과가 이 값과 다르면 집계 로직에 버그가 있는 것이다. `build/games-verify.js`가 이 값을 assert한다.

### 4.1 헤드라인 — 장르는 두 곳에 쏠려 있다

- **MMORPG + Shooter = 220종 / 328종 = 67.1%**
- TOP3(+ Card Game) = **76.2%**
- 장르 HHI = **2,476** (100점 만점 지분 제곱합 기준, 2,500 이상이면 고집중)
- 하위 6개 장르(Fighting~Racing) 합계 = 36종 = 11.0%

### 4.2 출시는 2014~2017에 몰렸다

| 구간 | 게임 수 | 비중 |
|------|--------:|-----:|
| 1997~2013 (17년) | 100 | 30.5% |
| **2014~2017 (4년)** | **108** | **32.9%** |
| 2018~2024 (7년) | 120 | 36.6% |

연도별 정점은 **2014년·2015년 각 29종**. 2024년은 9종이지만 **원본 스냅샷이 2024-07까지라 연도 미완결**이므로
차트에서 2024는 미완결 표시(빗금/점선 + 각주)를 해야 한다.

### 4.3 장르 쏠림의 주인공이 교체됐다 (히트맵)

같은 3년 단위 구간 집계에서:

| 장르 | 1997~2013 점유 | 2014~2024 점유 |
|------|---------------:|---------------:|
| MMORPG | 67 / 100 = **67%** | 60 / 228 = **26%** |
| Shooter | 18 / 100 = **18%** | 75 / 228 = **33%** |
| Card Game | 0 / 100 = 0% | 29 / 228 = 13% |

MMORPG는 절대 수(127)로는 여전히 1위지만, **2014년 이후 출시분에서는 Shooter에 1위를 내줬다.**
헤드라인(§4.1)과 히트맵을 같이 읽어야 "쏠림은 유지되고 주인공만 바뀌었다"가 성립한다.

**히트맵 구간(열, 8개)** — `1997-2003 / 2004-2006 / 2007-2009 / 2010-2012 / 2013-2015 / 2016-2018 / 2019-2021 / 2022-2024`
구간별 전체 게임 수: `9 / 15 / 29 / 33 / 72 / 70 / 47 / 53`

상위 6개 장르 실측 셀 값(검증용):

| 장르 | 97-03 | 04-06 | 07-09 | 10-12 | 13-15 | 16-18 | 19-21 | 22-24 |
|------|--:|--:|--:|--:|--:|--:|--:|--:|
| MMORPG | 8 | 13 | 19 | 21 | 21 | 25 | 6 | 14 |
| Shooter | 0 | 0 | 6 | 8 | 27 | 21 | 15 | 16 |
| Card Game | 0 | 0 | 0 | 0 | 6 | 13 | 5 | 6 |
| Strategy | 0 | 0 | 1 | 1 | 4 | 2 | 8 | 3 |
| MOBA | 0 | 0 | 1 | 1 | 4 | 6 | 2 | 4 |
| Fighting | 0 | 0 | 1 | 1 | 3 | 1 | 2 | 1 |

### 4.4 무료 게임 생태계는 늙어 있다

기준일 **2026-08-12**, 나이 = (기준일 − 출시일) / 365.2425일

| 지표 | 값 |
|------|-----|
| 중위 나이 | **10.3년** |
| 평균 나이 | 10.7년 |
| 10년 이상 | 173종 = **52.7%** |
| 15년 이상 | 69종 = 21.0% |
| 5년 미만 | 55종 = 16.8% |

카탈로그의 절반 이상이 10년 넘은 타이틀이다. "무료 게임 = 신작 실험장"이라는 통념과 반대.

### 4.5 참고 수치 (섹션으로는 만들지 않음)

퍼블리셔=개발사(자체 퍼블리싱) 207종 = 63.1%, 브라우저 동시 지원 11종.
사용자가 별도 섹션으로 선택하지 않았으므로 **KPI/푸터의 보조 수치로만** 노출한다.

## 5. 디자인 시스템

Wanted **Montage**(https://github.com/wanteddev/montage-web) 토큰을 그대로 사용한다.
`assets/dashboard.css`에 이미 옮겨져 있으므로 **재선언하지 않고 그 파일을 그대로 링크**한 뒤,
`assets/games.css`에서 이 페이지 전용 컴포넌트만 추가한다.

- 색: `--blue-50/40/30/90/95`, `--neutral-10/30/40/60/90/95/99` (semantic 별칭 경유)
- 타이포: `.display2 .title2 .heading1 .body1 .label1 .caption1`, Pretendard
- 간격/라운드: `--sp-*`, `--radius-*`
- **강조색은 blue 단색 하나.** 순위/양-음 비교가 없는 데이터이므로 red 다이버징 페어는 쓰지 않는다.
- 히트맵 색 스케일: `--blue-95 → --blue-50` 단일 순차(sequential), 값 0은 채색 없이 `--neutral-99`.
- 차트는 **라이브러리 없이 인라인 SVG**로 직접 그린다(기존 `dashboard.js`와 동일 방식).
- 언어: **UI/해설은 한국어**, 게임명·장르·퍼블리셔·설명문은 **원문 영어 그대로**.

### S6 탐색기 상세 (사용자 선택: 검색 + 장르/연도 필터 + 정렬)

- **검색** 텍스트 1개 — `title`, `publisher`, `developer`, `short_description` 대소문자 무시 부분일치. 입력 150ms 디바운스.
- **장르 셀렉트** — `전체(328)` + 정제 12종, 각 옵션에 게임 수 표기.
- **연도 셀렉트** — `전체` / `2020~2024` / `2015~2019` / `2010~2014` / `2005~2009` / `2004년 이전`.
- **플랫폼 셀렉트** — `전체` / `Windows 전용` / `브라우저 동시 지원`.
- **정렬 셀렉트** — `최신 출시순`(기본) / `오래된 출시순` / `제목 A→Z` / `장르순`.
- **초기화 버튼** — 모든 필터 리셋.
- **결과 라인** — `328종 중 27종` 형식. 0건이면 빈 상태 안내 문구 + 초기화 버튼.
- **카드** — 썸네일(16:9) / 제목 / 장르 배지 / 퍼블리셔 / 출시일(YYYY.MM.DD) / 설명 2줄 clamp / `FreeToGame에서 보기 ↗`(`freetogame_profile_url`, `target=_blank` + `rel="noopener noreferrer"`).
- **상세 모달·URL 상태 보존은 범위 밖**(사용자가 선택하지 않음). 구현하지 않는다.

**썸네일** (사용자 결정: 원본 URL 핫링킹)
`loading="lazy"`, `decoding="async"`, `referrerpolicy="no-referrer"`, 명시적 `width/height`(16:9 비율 박스)로 레이아웃 시프트 방지.
`onerror` 시 이미지 노드를 숨기고 **제목 이니셜 + `--neutral-99` 배경 플레이스홀더**로 대체(깨진 아이콘 노출 금지).

**파일**


**규칙**

- 집계는 **빌드 타임**에 끝낸다. 브라우저는 `games.json` 하나만 `fetch`한다(파일 크기 목표 200KB 이하).
- 소수 1자리 반올림. 백분율은 `게임 수 / 328 × 100`.
- 히트맵 셀 채색은 **행 내 비중** 기준이므로 표본 작은 행(Racing 3종)이 과하게 진해지지 않게
  행 합계 5건 미만 행은 `기타`와 함께 표에 남기되 캡션에 표본 주의를 적는다.
- 접근성: 모든 섹션 `aria-labelledby`, 차트는 `role="img"` + `aria-label` 요약, SVG 텍스트 최소 12px,
  키보드로 필터 전부 조작 가능, `sr-only` 제목 유지, 대비 4.5:1 이상.
- 반응형: 1180px 컨테이너, 카드 그리드 `repeat(auto-fill, minmax(240px, 1fr))`,
  히트맵/표는 `overflow-x: auto`로 감싸 **body 가로 스크롤 금지**. 768px 미만에서 필터 바 1열.
- 로딩 실패 시 각 섹션에 한국어 오류 문구 표시(무한 '불러오는 중' 금지).
- `index.html` 헤더에 `무료 게임 대시보드 →` 링크 추가, `games.html`에서 되돌아가는 링크 제공.

## 8. 데이터 한계 (S7 푸터 문안)

1. FreeToGame이 공개한 무료 PC 게임 목록의 **스냅샷(2024-07 기준)**이다. 이후 출시·서비스 종료는 반영되지 않으며, 목록에 서비스가 끝난 게임이 남아 있을 수 있다.
2. **평점·플레이어 수·매출 컬럼이 없다.** 이 페이지의 모든 수치는 '출시된 타이틀 수'이며 인기나 규모가 아니다.
3. 장르는 원본 18종을 12종으로 정제했다: `Card→Card Game`, `ARPG→Action RPG`, `MMOARPG→MMORPG`, `Action Game→Action`으로 병합한 뒤, 표본 3건 미만인 `Action RPG`·`Action`·`Fantasy`(총 5종)를 `기타`로 묶었다. `MMO`(6종)는 `MMORPG`와 합치지 않았다.
4. **2024년은 미완결**이다(원본이 2024-06-22까지). 2024 막대를 전년과 그대로 비교하면 안 된다.
5. 플랫폼은 PC 기준이다. 모바일·콘솔 버전이 있어도 원본에 표기되지 않아 집계에서 빠진다.
6. 게임 나이는 **2026-08-12 고정 기준일**로 계산했다. 페이지를 나중에 열어도 값은 바뀌지 않는다.
7. 썸네일은 freetogame.com에 원본 URL로 직접 연결한다. 원본이 내려가면 이미지가 표시되지 않는다.
8. 퍼블리셔·개발사 이름은 원본 문자열 그대로여서 표기 변형(법인 접미사 등)이 같은 회사를 다르게 셀 수 있다.
